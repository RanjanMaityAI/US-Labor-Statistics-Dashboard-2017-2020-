## US Labor Statistics Dashboard (2017–2020) | Advanced Excel Dashboard Project

#### 🟠 Project Description :-

This project is an interactive Excel dashboard built using US labor statistics data from 2017 to 2020. The dashboard was designed for Mojo Careers, a non-profit organization that helps high school seniors explore career opportunities and understand employment trends across industries and states in the United States.

The goal of the dashboard is to help users analyze :

    → Employment trends
    → Wage growth
    → Industry comparisons
    → State-wise labor statistics
    → Workforce distribution patterns

The dashboard provides an easy-to-use and interactive experience through filters, charts, maps and dynamic visualizations.
