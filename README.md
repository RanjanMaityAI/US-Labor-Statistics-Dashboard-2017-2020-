## US Labor Statistics Dashboard (2017–2020) | Advanced Excel Dashboard Project

#### 🟠 Project Description :-

This project is an interactive Excel dashboard built using US labor statistics data from 2017 to 2020. The dashboard was designed for Mojo Careers, a non-profit organization that helps high school seniors explore career opportunities and understand employment trends across industries and states in the United States.

The goal of the dashboard is to help users analyze :

    → Employment trends
    → Wage growth
    → Industry comparisons
    → State-wise labor statistics
    → Workforce distribution patterns

The dashboard provides an easy-to-use and interactive experience through filters, charts, maps and dynamic visualizations.

#### 🟠 Dashboard Development Process :-

The objective was to create an interactive dashboard for high school seniors so they could :

    → Compare industries
    → Analyze wage trends
    → Explore employment opportunities
    → Understand state-wise labor market differences
    
The raw labor statistics data was cleaned and organized before visualization.

Create KPIs :

    → Total Employees
    → Average Annual Wage
    → Total Establishments
    → Highest Paying Industry
    → State-wise Employment Distribution
    
Interactivity Added :

    → Industry dropdown
    → Dynamic charts
    → Interactive map visualization
    → Highlighted trend analysis
    
Primary Visuals :

    → Line Chart/Combo Chart → Wage & Employee Trends
    → Bar Chart → Avg Annual Wage by Industry
    → Map Chart → State-wise analysis
    → Doughnut Chart → Employee by Industry   
    → KPI Cards → Quick business insights

#### 🟠 Conclusion :-

The dashboard successfully transforms raw labor statistics into meaningful business insights. It helps high school seniors/users compare industries, analyze wage, employment trends and understand geographic workforce differences across the United States.
